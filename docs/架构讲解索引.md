# 5. 五个最核心设计句

```text
1. AgentRunSession 是跨 Turn 的 live state；
   PreparedTurn 是单 Turn 的 LLM input snapshot。

2. Context 不是统一 summary：
   History 做 compaction，Repo 做 retrieval，Skill 做 disclosure，
   Tools 做 routing，Permission 保持 authoritative。

3. ToolCall 是模型语言；
   OperationIntent 才是 Runtime 治理语言。

4. Resume 是 continuation，不是 Python live object resurrection。

5. Multi-Agent 中 LLM 提计划，Runtime 验计划；
   Worker 不共享完整 Conversation，只共享代码状态和结构化 Handoff。
```
