# 6. 下钻原则

```text
Capability
→ Application / Domain Owner
→ state transition
→ Repository / Port
→ Adapter I/O
→ tests / Trace evidence
```

先找谁拥有决定，再看文件 I/O；不要从模糊的 `run` / `save` / `update` 全局搜索开始。
