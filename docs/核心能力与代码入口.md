# 核心能力与代码入口

> 本文只提供第一个 canonical Owner。先打开 Application/Domain 的业务判断，再按类型
> 进入 Port 与 Adapter；架构解释由对应能力文档负责。

# 1. Single-Agent 主链只记 8 个 Owner

```text
Harness.run
→ AgentLoop.run
→ RunPreparation.prepare_run
→ TurnPreparation.prepare_turn
→ ModelGateway.chat
→ ToolExecutionPipeline._execute_call
→ FinalAnswerBuilder.build_stop_request
→ RunLifecycle.finalize_run
```

| Owner | 系统角色 | Source File |
|---|---|---|
| `Harness.run` | Public API、ExecutionEnvironment、Runtime 装配与 artifacts | `agent_forge/harness.py` |
| `AgentLoop.run` | 有界 Turn loop 与唯一运行控制流 | `agent_forge/runtime/application/agent_loop.py` |
| `RunPreparation.prepare_run` | 首轮前 guardrail、HITL、Skill、Memory 与 resume seed | `agent_forge/runtime/application/run_preparation.py` |
| `TurnPreparation.prepare_turn` | 当前 Turn 的 context、tools 与 prompt budget 汇合 | `agent_forge/runtime/application/turn_preparation.py` |
| `ModelGateway.chat` | Provider 调用、retry、normalization 与 usage | `agent_forge/runtime/adapters/model_gateway.py` |
| `ToolExecutionPipeline._execute_call` | ToolCall 的治理、执行与反馈 | `agent_forge/runtime/application/tool_execution.py` |
| `FinalAnswerBuilder.build_stop_request` | 模型文本到 typed stop candidate | `agent_forge/runtime/application/final_answer.py` |
| `RunLifecycle.finalize_run` | 终态质量门与 durable checkpoint | `agent_forge/runtime/application/run_lifecycle.py` |

# 4. Multi-Agent 入口

Planning 与 execution 是两个相邻 Application 入口：

```text
AdaptivePlanner.decide()
→ PlanningDecision.to_fanout_plan()
→ Application composition
→ FanoutCoordinator.run()
```

| 关注点 | Canonical Owner | Source File |
|---|---|---|
| Natural task → Single/Fanout proposal | `AdaptivePlanner.decide()` | `agent_forge/multi_agent/application/planning.py` |
| HARD/LIVE 图约束 | `FanoutPlan.__post_init__()` | `agent_forge/multi_agent/domain/live.py` |
| Scheduling、integration、recovery | `FanoutCoordinator.run()` | `agent_forge/multi_agent/application/fanout.py` |
| LIVE route、mailbox、freshness | `LiveHandoffRuntime.publish()` | `agent_forge/multi_agent/application/live_handoff.py` |
| 隔离 Worker 与 Finalizer | `LocalAgentWorkerAdapter.run_worker()` | `agent_forge/multi_agent/adapters/local_worker.py` |

完整闭环见 [多 Agent 编排](多Agent编排.md)。

# 5. 定位规则

```text
谁拥有业务判断？
→ Application / Domain Owner
→ Port
→ Adapter
→ Test / Trace 验证
```

- 查调用方：在 Owner 上使用 Find Usages，并将 Scope 限定到生产源码；
- 查 Port 实现：从 Protocol 使用 Go to Implementations；
- 查装配：打开对应 `wiring.py` 或 Public facade；
- 不从 UI、报告、测试或持久化产物反推核心控制流。
