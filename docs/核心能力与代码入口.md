# 1. Single-Agent 主链只记 8 个 Owner

```text
Harness.run
→ AgentLoop.run
→ RunPreparation.prepare_run
→ ModelStepPreparation.prepare_model_step
→ ModelGateway.chat
→ ToolExecutionPipeline._execute_call
→ FinalAnswerBuilder.build_stop_request
→ RunLifecycle.finalize_run
```

| Owner | 系统角色 | Source File |
|---|---|---|
| `Harness.run` | Public API、Thread/Turn/Run 绑定、ExecutionEnvironment 与 Runtime 装配 | `agent_forge/harness.py` |
| `AgentLoop.run` | Run 内有界 Model Step loop 与唯一运行控制流 | `agent_forge/runtime/application/agent_loop.py` |
| `RunPreparation.prepare_run` | 输入治理、冻结/复用 Turn snapshot 与 clarification barrier | `agent_forge/runtime/application/run_preparation.py` |
| `ModelStepPreparation.prepare_model_step` | 当前 Model Step 的 context、tools 与 prompt budget 汇合 | `agent_forge/runtime/application/model_step_preparation.py` |
| `ModelGateway.chat` | Provider 调用、retry、normalization 与 usage | `agent_forge/runtime/adapters/model_gateway.py` |
| `ToolExecutionPipeline._execute_call` | ToolCall 的治理、执行与反馈 | `agent_forge/runtime/application/tool_execution.py` |
| `FinalAnswerBuilder.build_stop_request` | 模型文本到 typed stop candidate | `agent_forge/runtime/application/final_answer.py` |
| `RunLifecycle.finalize_run` | accepted final、Run checkpoint 与 Turn 终态收口 | `agent_forge/runtime/application/run_lifecycle.py` |

# 4. Multi-Agent 入口

Public route 与 Planning / execution 是相邻 Application 入口：

```text
run_repository_task()
├── Single → Harness.run()
└── Ultra  → AdaptivePlanner.decide()
               ├── single → same Harness.run()
               └── multi  → FanoutPlan → FanoutCoordinator.run()
                                      └── _run_plan()
```

| 关注点 | Canonical Owner | Source File |
|---|---|---|
| Single / Ultra 公开路由 | `run_repository_task()` | `apps/repository_run.py` |
| Natural task → Single/Multi proposal | `AdaptivePlanner.decide()` | `agent_forge/multi_agent/application/planning.py` |
| Schema/Domain/Graph 校验与一次 repair | `AdaptivePlanner._request()` | `agent_forge/multi_agent/application/planning.py` |
| HARD/LIVE 图约束 | `FanoutPlan.__post_init__()` | `agent_forge/multi_agent/domain/live.py` |
| HARD/LIVE 统一 readiness scheduling | `FanoutCoordinator._run_plan()` | `agent_forge/multi_agent/application/fanout.py` |
| Candidate integration / recovery | `FanoutCoordinator._integrate_result()` | `agent_forge/multi_agent/application/fanout.py` |
| LIVE route、mailbox、freshness | `LiveHandoffRuntime.publish()` | `agent_forge/multi_agent/application/live_handoff.py` |
| 隔离 Worker 与 Finalizer | `LocalAgentWorkerAdapter.run_worker()` | `agent_forge/multi_agent/adapters/local_worker.py` |
| Worker/Finalizer private Thread | `ConversationThread` | `agent_forge/runtime/domain/thread.py` |

完整闭环见 [多 Agent 编排](多Agent编排.md)。

# 5. 定位规则

```text
谁拥有业务判断？
→ Application / Domain Owner
→ Port
→ Adapter
→ Test / Trace 验证
```

- 查调用方：在 Owner 上使用 Find Usages，并将 Scope 限定到生产源码；
- 查 Port 实现：从 Protocol 使用 Go to Implementations；
- 查装配：打开对应 `wiring.py` 或 Public facade；
- 不从 UI、报告、测试或持久化产物反推核心控制流。
