# 核心能力与代码入口

本文只回答一个问题：**已经知道能力名称时，第一段应该打开哪段核心代码**。表中的 Owner
是该能力的首个阅读入口，不是所有相关文件的罗列；点击符号可直接进入定义，符号名也可用于仓库搜索。

运行规则、失败分支和恢复行为见[核心运行机制与代码索引](核心运行机制与代码索引.md)；模块依赖和
类型契约见[项目架构与代码导航](项目架构与代码导航.md)。本文不重复解释机制正文。

## 最小主链

一次 Single-Agent Run 的最短代码路径由下面八个 Owner 构成。遇到具体能力，再查后续索引。

| 顺序 | Owner | 只负责什么 |
| --- | --- | --- |
| ① | [`Harness.run`](../agent_forge/harness.py#L89) | 接收公开请求，创建运行产物和执行环境，装配并启动 Runtime |
| ② | [`AgentLoop.run`](../agent_forge/runtime/application/agent_loop.py#L76) | 编排 Run 准备、Turn、模型、Tool 和唯一终态 |
| ③ | [`RunPreparation.prepare_run`](../agent_forge/runtime/application/run_preparation.py#L109) | 在首个 Turn 前处理澄清、Skill、Memory 和恢复摘要 |
| ④ | [`TurnPreparation.prepare_turn`](../agent_forge/runtime/application/turn_preparation.py#L88) | 为本轮组装 Context、压缩预算并确定可见 Tool |
| ⑤ | [`ModelGateway._call_with_retry`](../agent_forge/models/gateway.py#L111) | 调用 Provider，执行有界重试、备用模型和错误归一化 |
| ⑥ | [`ToolExecutionPipeline._execute_call`](../agent_forge/runtime/application/tool_execution.py#L181) | 串起 ToolCall 复核、操作状态、授权、执行和 Observation 提交 |
| ⑦ | [`FinalAnswerBuilder.build_stop_request`](../agent_forge/runtime/application/final_answer.py#L22) | 把模型最终输出转换为类型化停止请求 |
| ⑧ | [`RunLifecycle.finalize_run`](../agent_forge/runtime/application/run_lifecycle.py#L96) | 统一提交最终状态、停止原因、Trace 和 Checkpoint |

## 按需能力快速跳转

这些能力不在每个 Run 中出现，只需记住各自的顶层 Owner。

| 能力 | 顶层 Owner | 下钻条件 |
| --- | --- | --- |
| Skill 选择与激活 | [`SkillRegistry.discover_for_task`](../agent_forge/skills/registry.py#L64)、[`SkillRegistry.activate`](../agent_forge/skills/registry.py#L131) | 需要解释激活词、兜底、版本锁定或渐进披露时 |
| 长期记忆 | [`LongTermMemoryService.recall`](../agent_forge/context/application/memory_service.py#L150) | 需要解释作用域、覆盖规则和跨 Run 召回时 |
| 顺序 Multi-Agent | [`MultiAgentCoordinator.run`](../agent_forge/multi_agent/application/coordinator.py#L55) | 需要解释 Implementer、Reviewer、Verifier 交接时 |
| Fanout 并发与合并 | [`LiveFanoutCoordinator.run`](../agent_forge/multi_agent/application/live_fanout.py#L55) | 并发进入 [`LiveFanoutCoordinator._run_batch`](../agent_forge/multi_agent/application/live_fanout.py#L342)，合并进入 [`LiveFanoutCoordinator._merge_batch`](../agent_forge/multi_agent/application/live_fanout.py#L404) |
| Fanout 恢复与最终验收 | [`LiveFanoutCoordinator._checkpoint`](../agent_forge/multi_agent/application/live_fanout.py#L575) | 恢复进入 [`LiveFanoutCoordinator._restore_previous`](../agent_forge/multi_agent/application/live_fanout.py#L471)，整体检查进入 [`LocalAgentWorkerAdapter.run_finalizer`](../agent_forge/multi_agent/adapters/local_worker.py#L248) |
| SWE-bench 单次运行 | [`RunSwebench.run_benchmark`](../agent_forge/bench/application/swebench.py#L20) | 需要解释 Case、Workspace、Patch 和官方评测产物时 |
| 重复实验 | [`RunBenchmarkCampaign.run_campaign`](../agent_forge/bench/application/campaign.py#L64) | 需要解释固定输入、实验变体和增量恢复时 |
| 失败分类与 Scorecard | [`classify_case_result`](../agent_forge/bench/domain/failure_taxonomy.py#L45)、[`aggregate_cases`](../agent_forge/evaluation/domain/scorecard.py#L114) | 需要解释确定性分类、分母和证据等级时 |
| MCP stdio Tool | [`MCPStdioClient.discover_tools`](../agent_forge/tools/mcp_stdio.py#L30)、[`MCPStdioClient.call_tool`](../agent_forge/tools/mcp_stdio.py#L42) | 需要解释发现远端 Tool 和 JSON-RPC 调用时 |
| 实时操作台 | [`OperatorConsoleApp`](../agent_forge/operator_console/app.py#L239) | 需要检查人工控制界面如何调用正式 Runtime 时 |
| 只读 Workbench | [`WorkbenchServices`](../agent_forge/workbench/application/services.py#L12) | 需要检查 Trace、Checkpoint 和评测证据如何展示时 |

## 代码审阅优先级

| 优先级 | 目录 | 阅读原则 |
| --- | --- | --- |
| 核心 | `agent_forge/runtime/application/`、`runtime/domain/`、`context/application/`、`tools/`、`safety/` | 能力的业务编排、状态和治理规则优先从这里进入 |
| 按需 | `multi_agent/application/`、`bench/application/`、`evaluation/`、`skills/` | 只有涉及对应能力时才打开 |
| 边界实现 | `*/adapters/`、`runtime/execution_environment.py` | 需要确认 JSON 持久化、协议或外部执行细节时再下钻 |
| 展示层 | `operator_console/`、`workbench/presentation/` | 用于界面和证据投影，不作为 Runtime 规则的首个入口 |
| 支撑代码 | `agent_forge/cli/`、`scripts/`、`.github/`、安装配置 | 负责参数接入、环境搭建和自动化，不用于理解核心机制 |
| 验证代码 | `tests/`、`examples/debug_lab/` | 在找到 Owner 后，用于核对行为和运行证据，不反向充当机制 Owner |

最小检索规则：**先按能力名称打开本页的首个 Owner；只有需要解释行为和异常分支时，才进入
[核心运行机制与代码索引](核心运行机制与代码索引.md)。**
